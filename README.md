# OTG Server 8.60

# ✨ Por que usar o OTG Server 8.60?

O **OTG Server 8.60** é a nossa base OpenTibia com **suporte nativo ao cliente 8.6** — protocolo
8.60 real (handshake XTEA/RSA, login e serialização de pacotes fiéis ao cliente clássico) — sem
precisar de "adaptação visual" por outro cliente. Você joga no Tibia 8.6 de verdade, com toda a
estabilidade e os sistemas modernos que a engine OTG já oferece.

## 🚀 Benefícios e Otimizações

- **🐴 Cliente 8.6 nativo** — loga direto no cliente 8.60 clássico, com protocolo real (não é só um "visual patch").
- **🔥 Baixíssimo uso de CPU em NPCs e Monstros** — o tick de criaturas foi enxuto para aguentar mundos populosos sem travar o processador.
- **🧭 Pathfinder otimizado** — busca de caminho mais rápida e com bem menos alocações, deixando monstros e NPCs muito mais responsivos.
- **👀 `getSpectator` otimizado** — varredura de espectadores muito mais eficiente, cortando o custo dos broadcasts de pacotes no mundo.
- **💀 `onDecay` otimizado** — gerenciamento de decay de itens mais leve, menos gargalos em áreas com muito loot.
- **🛡️ Base limpa e estável** — código revisado, livre de modificações maliciosas, compatível com sistemas e clients modernos:
  **Otc Redemption, Otcv8, Store System, Imbuements, Prey, Market, Trade NPC, Charms, Bestiary**.

## 💙 Um projeto feito com carinho

Somos uma comunidade séria e apaixonada por OpenTibia, fundada por brasileiros. Cada otimização
aqui foi pensada para o seu servidor rodar **liso, leve e divertido** — do clássico 8.6 até os
sistemas mais modernos. Você tem o melhor dos dois mundos: a nostalgia do 8.6 com a robustez de uma
engine moderna.
